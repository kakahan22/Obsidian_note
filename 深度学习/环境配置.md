# Anaconda+vscode
## 安装虚拟环境（conda）

```
conda create -n 虚拟环境名字 python=版本 //利用conda创建虚拟环境
conda env list //查看conda下面有哪些虚拟环境
conda activate 虚拟环境名称//激活环境
conda list //查看虚拟环境下的包
conda deactivate //退出一个虚拟环境
conda remove -n 虚拟环境名字 --all//删除虚拟环境
```
## 配置CUDA
cuda runtime 调用cuda driver（显卡驱动），cuda driver调用我们的cuda做并行运算，遵循规则：
cuda runtime version <=cuda driver version =匹配的算力
```
任务管理器确定自己显卡型号
然后去确定自己的算力(https://developer.nvidia.com/cuda/gpus#compute)
nvidia-smi //确定自己的cuda driver版本
打开pytorch，确定自己的版本对应的pytorch，会有下载的conda指令
然后在anaconda环境中创建环境，激活环境然后下载pytorch
```
## vscode配置
创建文件，右下角选择解释器，选择虚拟环境里面的解释器就可以成功了。
