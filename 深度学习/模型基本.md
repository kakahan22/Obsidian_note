
# 模型选择
## 误差
1.训练误差：训练数据上的误差，训练集
2.**泛化误差**：新数据集上的误差，测试集
数据集：
1.训练集：训练模型参数
2.验证集：不参与训练，用来验证超参数
ps：划分验证集和训练集，我们使用k-折交叉验证法[[模型基本#k-折交叉验证法]]
3.测试集：只使用一次。
## k-折交叉验证法
将我们的数据集k（k一般取5或者10）等分，然后我们选择其中的第i份作为我们的验证数据集，其他的作为训练集。然后我们再选择一次，进行训练验证，重复三次。取三次计算的平均值作为我们的准确率和误差率。

# 拟合和过拟合
## 模型容量
·衡量模型拟合各种函数的能力
·低容量的模型容易欠拟合，高容量模型容易过拟合（一根曲线线拟合所有的点）
### 模型的最优点
即是泛化误差最低点。
![[./图片/截屏2026-09-07 19.13.19.png]]
### 模型容量决定因素
1.不同种类的算法之间难比较
2.给定一个模型种类，模型的容量主要有两个因素：参数的多少，和参数的可取范围。

## 如何避免过拟合？
### 权重衰减
过拟合的原因是：某个参数过大，所以我们解决过拟合，就是要让我们的权重尽可能的每次增加的缓一点点，其实就是我们的梯度尽可能的接近0，所以我们将我们的loss= loss+$\theta$ ,这个$\theta$ 就是权重。
#### 优化一：硬性限制
为了处理过拟合，我们通过均方范数作为硬性限制。要求：
	$min \quad l(w,b)\quad subject\quad to ||w||^{2}<=\theta$
	通常我们不限制b，小的$\theta$意味着更强的正则项

#### 优化二：柔性限制
对每个$\theta$ ,都可以找到$\epsilon$ 使得之前的目标函数等价于下面的
	$min \quad l(w,b)+\frac{\epsilon}{2}||w||^{2}$
超参数$\epsilon$ 控制了正则项的重要程度（如果正则项大一点，则说明重要程度高，如果不重要，我们可以让$\epsilon$小一点）

```
def init_params():

w = torch.normal(0, 1, size=(num_inputs, 1), requires_grad=True)

b = torch.zeros(1, requires_grad=True)

return w, b

  

# L2范数惩罚

def l2_penalty(w):

return torch.sum(w.pow(2)) / 2

  

#训练函数

def train(lambd):

w, b = init_params()

net,loss = lambda X: d2l.linreg(X, w, b), d2l.squared_loss

num_epochs, lr = 150, 0.003

animator = d2l.Animator(xlabel='epoch', ylabel='loss', yscale='log', xlim=[5, num_epochs], legend=['train', 'test'])

for epoch in range(num_epochs):

for X, y in train_iter:

#with torch.enable_grad():

l.sum().backward()

d2l.sgd([w, b], lr, batch_size)

if (epoch + 1) % 5 == 0:

animator.add(epoch + 1, (d2l.evaluate_loss(net, train_iter, loss), d2l.evaluate_loss(net, test_iter, loss)))

  

print('w的L2范数是：', torch.norm(w).item())
//w的L2范数是： 0.021957898512482643
  
train(8)
```

##### 简洁实现权重衰减
直接用weight_decay=wd解决
```
%matplotlib inline

import torch

from torch import nn

from d2l import torch as d2l
n_train, n_test, num_inputs, batch_size = 20, 100, 200, 5

  

true_w, true_b = torch.ones((num_inputs, 1)) * 0.01, 0.05

  

train_data = d2l.synthetic_data(true_w, true_b, n_train)

  

train_iter = d2l.load_array(train_data, batch_size)

  

test_data = d2l.synthetic_data(true_w,true_b, n_test)

  

test_iter = d2l.load_array(test_data, batch_size, is_train=False)

# 初始化模型

def init_params():
    w = torch.normal(0, 1, size=(num_inputs, 1), requires_grad=True)
    b = torch.zeros(1, requires_grad=True)

    return w, b

def train_concise(wd):
    net = nn.Sequential(nn.Linear(num_inputs, 1))
    for param in net.parameters():
        param.data.normal_(0, 1)
    loss = nn.MSELoss()
    num_epochs, lr = 150, 0.003
    trainer = torch.optim.SGD(net.parameters(), lr=lr, weight_decay=wd)
    animator = d2l.Animator(xlabel='epoch', ylabel='loss', yscale='log', xlim=[5, num_epochs], legend=['train', 'test'])
    for epoch in range(num_epochs):
        for X, y in train_iter:
            trainer.zero_grad()
            l = loss(net(X), y)
            l.backward()
            trainer.step()
        if (epoch + 1) % 5 == 0:
            animator.add(epoch + 1, (d2l.evaluate_loss(net, train_iter, loss), d2l.evaluate_loss(net, test_iter, loss)))

    print('w的L2范数是：', net[0].weight.data.norm().item())

train_concise(8)  # 权重衰减
```

### 丢弃法
怎样避免过拟合，除了权重衰减，还可以使用丢弃法（加入噪声）
1.一个好的模型需要对输入数据的扰动鲁棒
2.使用有噪声的数据等价于tikhonov正则
3.丢弃法：就是在层之间加入随机的噪声。
实现如下（就是对一部分的数据进行处理）
#### 无偏差的加入噪音
1.对于x加入噪音得到$x^{'}$ ，我们希望
	$E[x^{'}]=x$
	理解为可逆？
2.丢弃法对每个元素进行如下扰动：
	$对于有p概率的数据，x^{'}_{i}=0;对于1-p概率的数据，x^{'}_{i}=\frac{x_{i}}{1-p}$
这里的概率p是一个超参数
#### 丢弃法作用位置
通常将丢弃法作用在隐藏全连接层的输出上(即训练阶段)
![[./图片/截屏2026-09-08 18.53.08.png]]

**注意：不管是前面的权重衰减，还是现在的丢弃法，正则项都只在训练阶段使用，去影响我们参数的更新。在推理过程，他们直接返回输出，也就是说不影响任何，比如h=dropout(h)**

#### 丢弃法实现
##### 丢弃法从0开始实现

```
%matplotlib inline

import torch

from torch import nn

from d2l import torch as d2l

# 函数以dropout的概率丢弃张量输入x中的元素
def dropout_layer(X,dropout):
    assert 0<=dropout<=1
    if dropout == 0:
        return X
    elif dropout ==1:
        return torch.zeros_like(X)
    else:
        # mask是生成一个以dropout的概率丢弃元素的张量
        # 这里随机数<=dropout：得到0，丢弃，概率为dropout
        # 随机数>dropout：得到1，保留，概率为1-dropout
        mask = (torch.randn(X.shape)>dropout).float()
        return mask* X/(1.0-dropout)

X= torch.arange(16,dtype=torch.float32).reshape(2,8)
print(X)
print(dropout_layer(X,0.))
print(dropout_layer(X,1))
print(dropout_layer(X,0.5))

num_inputs,num_outputs,num_hidden1,num_hidden2=784,10,256,256
dropout1,dropout2= 0.2,0.5

class Net(nn.Module):
    def __init__(self,num_inputs,num_outputs,num_hidden1,num_hidden2,is_train=True):
        super(Net,self).__init__()
        self.num_inputs=num_inputs
        self.training=is_train
        self.num_outputs=num_outputs
        self.num_hidden1=num_hidden1
        self.num_hidden2=num_hidden2
        self.lin1 = nn.Linear(self.num_inputs,self.num_hidden1)
        self.lin2 = nn.Linear(self.num_hidden1,self.num_hidden2)
        self.lin3 = nn.Linear(self.num_hidden2,self.num_outputs)
        self.relu= nn.ReLU()

    def forward(self,X):
        H1 = self.relu(self.lin1(X.reshape(-1,self.num_inputs)))
        if self.training==True:
            H1 = dropout_layer(X,dropout1)
        H2=self.relu(self.lin2(H1))
        if self.training==True:
            H2=dropout_layer(X,dropout2)
        out = self.lin3(H2)
        return out

net = Net(num_inputs,num_outputs,num_hidden1,num_hidden2)
num_epochs,lr,batch_size=10,0.5,256
loss=nn.CrossEntropyLoss()
train_iter,test_iter=d2l.load_data_fashion_mnist(batch_size)
trainer = torch.optim.SGD(net.parameters(),lr=lr)
d2l.train_ch3(net,train_iter,loss,num_epochs,trainer)
```
